# MediAgenda 🏥
Sistema de gestión de citas médicas para consultorios privados.

## Descripción
MediAgenda permite a los pacientes agendar, modificar y cancelar citas médicas desde el celular, sin necesidad de llamar al consultorio. Los médicos tienen visibilidad completa de su agenda del día y el sistema envía recordatorios automáticos a los pacientes.
